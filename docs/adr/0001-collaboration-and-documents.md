# 개발 협업과 문서의 역할

Sift는 사람과 에이전트가 근거를 놓고 논의하며 제품을 만들기로 했다. 중요한 제품·아키텍처·개발 방식은 합의한 뒤 확정하고, 에이전트는 조사·검증과 합의된 작업을 진행하며 발견을 공유한다.

에이전트 작업 지침은 `AGENTS.md`, 제품 범위는 `docs/product.md`, 지속할 결정과 이유는 `docs/adr/`에 둔다. 조사 메모는 저장소 밖 임시 파일에 두고 채택한 근거와 결론만 해당 문서에 반영한다. 이렇게 구분해 잠정적인 조사와 확정된 결정을 혼동하지 않고, 필요한 규칙을 실제 작업에 맞춰 추가한다.
