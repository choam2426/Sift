# 2차 분석은 A를 먼저 기준선으로 만든다

Sift의 2차 분석에서는 코드 관계를 규칙으로 묶고 Jev가 재선별하는 A를 먼저 구현·평가해, 이후 다른 방식과 비교할 기준선으로 고정한다. [기존 결정](0003-jev-then-llm.md)은 관련 코드 선택과 2차 판단 주체를 비교하도록 남겨 두었지만, 여러 방식을 동시에 만들기 전에 A의 관계 추출, 맥락 누락, 버그 도달과 비용을 관찰할 수 있어야 비교가 의미 있다. 이번 단계에서 B·C는 실행하지 않으며, 향후 비교에는 [A 실험 설계](../../experiments/second-pass/README.md)의 동일한 입력 스냅샷과 예산을 사용한다. 1차 점수순은 A의 영향을 살피는 내부 참조로 보관한다.
