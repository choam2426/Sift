# ADR 0011: Phase 2는 파일럿에서 종료하고 확증 주장을 하지 않는다

- 날짜: 2026-11-09
- 상태: 채택
- 관련: [ADR 0009](0009-conclude-research-after-stage-0.md)(Phase 1 결론), [ADR 0010](0010-phase2-planted-defects.md)(Phase 2 설계)

## 맥락

[ADR 0009](0009-conclude-research-after-stage-0.md)는 개발 사례 4개에서 Jev가 긴 탐색의 비용을 줄였지만, 검증 실패가 그 이득을 대부분 상쇄했다고 결론 내렸다. 이 결과는 탐색적이었고 Jev 순위의 증분 효과를 단순한 코드 순위 목록과 분리하지 못했다.

[ADR 0010](0010-phase2-planted-defects.md)은 이를 독립 사례에서 확인하기 위해 학습 기준일 이후 리비전에 인가 결함을 심은 사례 13개와 `vanilla` / `rank-bm25` / `rank-jev` 3-arm 실험을 설계했다. 본 실험 전에 대형 저장소 2개와 중형 저장소 1개의 `vanilla` 파일럿으로 조사 범위·비용 상한·반복 수를 정하기로 했다.

### 파일럿 결과

mtime 누출 때문에 무효로 한 최초 3회는 [ADR 0010](0010-phase2-planted-defects.md)에 기록했다. 누출을 고친 뒤 실행한 결과는 다음과 같다. 비용은 Claude 비용이며 순위 비용은 없는 `vanilla` 실행이다.

| 범위 | 사례 | 비용 | 턴 | 기술 판정 | valid |
| --- | --- | ---: | ---: | --- | --- |
| 저장소 전체 | Argo CD | $20.160 | 170 | reproduced | 예 |
| 저장소 전체 | Gitea | $23.794 | 270 | no-finding | 아니오 |
| 저장소 전체 | Grafana | $24.452 | 210 | no-finding | 아니오 |
| 최상위 디렉터리 | Gitea (`services/`) | $16.741 | 204 | reproduced | 예 |
| 최상위 디렉터리 | Grafana (`pkg/`) | $25.690 | 305 | rejected | 아니오 |

저장소 전체 범위는 valid 1/3이라 ADR 0010의 규칙에 따라 최상위 디렉터리로 좁혔다. 최상위 디렉터리는 2회 중 1회만 valid인 시점에 종료했다. Argo CD 최상위 디렉터리 파일럿은 실행하지 않았으므로 이 범위가 2/3 기준을 통과했는지는 알 수 없다.

누출을 고친 뒤의 `rank-jev` 또는 `rank-bm25` 실행은 없다. 본 실험 13개 사례도 실행하지 않았다. 따라서 Phase 2에는 Jev 효과를 추정할 수 있는 결과가 없다.

## 결정

**Phase 2를 파일럿에서 종료하고 본 실험을 실행하지 않는다.**

- 남은 Argo CD 최상위 디렉터리 파일럿과 13개 사례의 본 실험 큐를 실행하지 않는다.
- H1(`rank-jev` 대 `vanilla`), H2(`rank-jev` 대 `rank-bm25`), H3(저장소 크기에 따른 효과)는 모두 **미평가**로 둔다. 지지·반박·결론 보류 중 하나로 판정하지 않는다.
- 이 종료를 “Jev 효과가 없다”는 근거로 쓰지 않는다. Phase 2에는 유효한 Jev 비교 실행이 없었다.
- Phase 1의 최종 결론과 제품 판단은 [ADR 0009](0009-conclude-research-after-stage-0.md) 그대로 유지한다.
- 사례 생성기, 13개 사례 정의, 실행·평가 harness와 분석 코드는 후속 연구의 설계 자료로 보존하지만 활성 실험으로 운영하지 않는다. 저장소 밖 원자료도 삭제하지 않는다.

## 이유

1. **완주 비용이 추가 정보의 가치보다 크다.** 수정된 파일럿의 `vanilla` 한 회는 $16.74~$25.69와 170~305턴을 썼다. 13개 사례 × 3arm은 반복 한 번만 해도 39회이며, 실행 간 변동을 다루려면 반복이 더 필요하다. 현재 사용 가능한 모델 실행량으로는 사전 설계의 의미를 유지한 채 완주하기 어렵다.
2. **제품 판단은 이미 바뀌지 않는다.** Phase 1에서 탐색 비용의 조건부 이득은 관측했지만 valid finding당 비용 차이는 2.5%였고, 병목은 test 작성·검증이었다. Phase 2의 작은 탐색적 표본을 더해도 Jev를 제품화하지 않고 검증 지원을 우선한다는 판단을 뒤집기 어렵다.
3. **더 작게 줄이면 다른 연구가 된다.** 사례·arm·반복을 결과와 자원 상황을 본 뒤 줄이면 ADR 0010의 H1~H3를 검증하는 실험이 아니게 된다. 저가 모델이나 낮은 effort로 바꾸면 Phase 1·파일럿과 비교 조건도 달라진다.
4. **중단은 Jev 결과를 보고 내린 선택이 아니다.** 누출 수정 후 Jev와 BM25 arm을 실행하기 전에 자원·실행 가능성을 근거로 중단한다. 따라서 선택적 중단으로 Jev의 방향을 해석하지 않는다.

## 결과의 지위

Phase 2가 남긴 것은 효과 추정치가 아니라 다음의 실행 가능성 자료다.

- post-cutoff 리비전에 새 결함을 심고 기존 오라클로 비등가 변이를 선별하는 절차
- 취약·수정·decoy 세 트리에서 제출 테스트를 반복 판정하는 평가기
- Docker·네트워크를 에이전트에서 분리한 broker
- mtime·빌드 캐시·고아 test helper가 결함 위치를 누설할 수 있다는 관측과 대응
- 저장소 전체 범위의 인가 결함 탐색이 실행당 $20 안팎에서도 자주 valid finding에 도달하지 못한다는 파일럿 관측
- Grafana 최상위 디렉터리 파일럿은 심은 결함이 아닌 **실제 인가 결함 1건**을 찾았다. 별도 비공개 VDP로 신고했고, 내용·PoC·제출 ID는 embargo 때문에 이 저장소에 기록하지 않는다. 이 발견은 Jev 효과의 증거가 아니다.

이 자료로 Jev, BM25 또는 vanilla의 상대 성능을 주장하지 않는다.

## 후속 연구 재개 조건

후속 연구는 이 큐를 그대로 이어서 결과를 합치지 않고 새 프로토콜로 시작한다. 다음 조건이 충족될 때 재검토한다.

1. 고정 모델·effort로 필요한 반복을 완주할 실행 예산이 있다.
2. 실제 제품 결정이 `rank-jev`와 싼 순위 기준의 차이를 요구한다.
3. 독립 실제 사례나 더 대표성 있는 심은 결함 집합을 확보한다.
4. 사례 수·arm·반복·중단 규칙을 첫 실행 전에 다시 고정한다.

증분 효과만 필요하다면 새 연구는 `rank-bm25` 대 `rank-jev` 2-arm으로 좁힐 수 있다. 그러나 이는 ADR 0010의 3-arm Phase 2를 축소 재개하는 것이 아니라 별도의 질문과 표본 계획을 가진 연구다.
