# 로드맵 — 전제 중심 (D14 수립, D16 개정)

> 찾을 수 있다. 범위는 전 버그 종류 (로직 한정 아님, D16).

## G1: 정적분석 완증 (진행 중)

4트랙 (Mastodon / 7-Zip / Kanidm / K8s-RBAC)에서 E2E로 증명.

Exit 조건:

```text
1. 단일 LLM 대비 비용 1/10 이하로 동등 이상 recall
2. CodeQL 대비 전체 범위에서 recall 동등 이상 + 비용 우위 (D16)
3. 대형 1개에서 Top-k 안정성 확인
```

agentic 대비는 문헌 수치 인용으로만 참고 (재현 안 함).
