# 첫 비교의 에이전트를 Pi와 Muse Spark 1.3 Contributor/high로 고정한다

2026-10-01 결정. 첫 비교의 두 실험군은 모두 최소 Pi 에이전트 `0.99.2`, Pi 내장 `meta` 공급자의 OAuth 로그인, `muse-spark-1.3-contributor`, reasoning effort `high`를 사용한다. 같은 하네스와 주 모델을 사용해 Jev를 활용하는 Sift 방식의 차이만 비교하고, 충분한 OAuth 사용량으로 반복 실행을 가능하게 하기 위해 선택했다. Pi의 내장 Meta 로그인을 사용하며 별도의 Meta 인증 확장은 쓰지 않는다.

고정 전에 프로젝트 문맥·도구·세션 저장을 끈 최소 호출이 `META_OK`를 반환했고, 임시 파일을 읽는 도구 호출 왕복도 `TOOL_OK`로 완료됐다. 확인 당시 Pi가 표시한 모델 식별자는 `muse-spark-1.3-contributor`이고 reasoning과 1,048,576 토큰 문맥을 지원했다.

두 군의 Pi 버전, 공급자, 모델, effort와 실행 설정을 같게 유지한다. 원격 모델은 같은 식별자 아래에서 바뀔 수 있으므로 실행일, Pi 버전, 응답의 모델 식별자와 사용량을 실행 기록에 남긴다. Contributor에 입력한 내용은 Meta 제품 개선에 사용될 수 있으므로 이 조합은 공개 개발·평가군에만 쓰고, 비공개 대상과 전향적 판정군의 모델·데이터 경로는 사용 전에 다시 결정한다.
