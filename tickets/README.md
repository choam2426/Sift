# Tickets

Local tracker (no remote). One file per ticket: `NNN-slug.md`.

## Statuses

`open` → `ready` → `doing` → `done`. One ticket in `doing` at a time.

## Rules

- Pick the next `ready` ticket; flip to `doing` when starting.
- Paste evidence (counts, sample rows, file links) in a `## Notes` section.
- Flip to `done` only when every `Done when` box holds.
