# 스펙

2026-09-29 상태: 작성 전. 목차는 [ADR 0017](../docs/adr/0017-provide-spec-and-materials.md)에서 정했다.

구축된 분석기가 보장해야 할 것을 적는다. 구현 언어와 도구는 정하지 않는다.

1. 범위와 용어: 분석 유닛, 출발점, 묶음, 구성, 범위 기록
2. 1차 전수 선별: 입력, 질문, 선별 규칙, 보장
3. 함수 추출: 모든 구성을 본다, 함수는 끝 위치로 식별해 중복을 없앤다, 매크로가 만든 본문은 "못 봄"으로 보고한다
4. 2차 묶음 재선별: 규칙 후보, 크기 한도와 채우는 순서, 선택 절차
5. 범위 기록: 모든 줄은 평가됐거나 "못 봄"으로 보고된다. 배부와 판정 기록 형식
6. Jev 호출: 캐시와 재개, 동시 전송 중복 제거, 예산 상한, 계정 오류에서 멈춤, 잘린 기록 허용
7. 실행 디렉터리 형식
8. 적합성 시험: `conformance/`의 입력, 기대 결과, Jev 모의 응답, 검사기

적합성 시험의 씨앗은 참조 구현의 테스트 픽스처(`boilerplate/tests/fixtures/`)다.
